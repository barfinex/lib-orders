# Barfinex Orders

Order management library for handling trading orders and positions.

## ✨ Features
- Written in TypeScript
- Reusable across Barfinex ecosystem
- Designed for modular microservices

## 📦 Installation
```bash
npm install @barfinex/orders
```

## 🚀 Usage
```ts
import { Example } from "@barfinex/orders";
```
